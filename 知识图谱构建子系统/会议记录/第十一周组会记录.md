- 编码 utf8mb4，CSV 用 UTF-8-SIG 写出  

**Neo4j**

- 远程实例可连（bolt://47.96.152.190:7687）  
- 导入脚本：`import_artifacts.py`，支持 `--batch-size` 调小防 OOM

**同步链路**

```
CSV → csv_db_sync.py → MySQL
CSV → export_kg.py → output/kg/ → neo4j_sync.py → Neo4j
```
