## 四、数据流水线（定稿）

```
海外博物馆网站
    ↓ museum_spider.py
CSV + 本地图片（output/）
    ↓ clean_data.py / entity_align.py / wikidata_enrich.py
清洗后数据 + 三元组（output/kg/）
    ↓ db.py + neo4j_sync.py
MySQL（7151 条）+ Neo4j（143623 边）
    ↓ backend/main.py（FastAPI）
REST API → Web / App / 问答 / 后台
```
