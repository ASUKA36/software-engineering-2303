## 一、项目概述

本项目是一个海外文物知识服务子系统，旨在为用户提供海外文物的浏览、搜索、收藏、评论等功能，同时支持文物知识图谱展示和时间轴可视化浏览。

## 五、部署与运行

### 5.1 后端运行

```bash
cd museum
# 使用Maven Wrapper启动（无需安装Maven）
./mvnw spring-boot:run

# 或打包后运行
./mvnw clean package
java -jar target/demo-0.0.1-SNAPSHOT.jar
```

### 5.2 前端运行

```bash
cd myvue
# 安装依赖
npm install

# 开发模式运行
npm run dev

# 生产环境构建
npm run build
```

## 七、关键特性

### 7.1 密码加密

采用 **MD5 + 盐值 + 三重加密** 方案，确保用户密码安全。

### 7.2 敏感词审核

实现三级审核策略：
- 低风险（≤20分）：自动通过
- 中风险（≤60分）：人工复审
- 高风险（>60分）：自动拒绝

### 7.3 图片加载策略

根据博物馆ID选择不同图片源：
- 博物馆1：直接使用URL
- 博物馆2、3：调用服务器接口

## 八、项目说明

本项目采用前后端分离架构，前端基于Vue 3 + Vite构建，后端使用Spring Boot框架，结合MySQL和Neo4j两种数据库，实现文物数据的结构化存储和知识图谱关联分析。
