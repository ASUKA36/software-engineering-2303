## 第一次会议纪要 — 需求分析与项目规划

**会议性质**：项目启动与需求分析会议

### 主要内容：
1. **需求分析**：
   - 数据浏览：按时间排序文物、按类型归类、查看文物详细信息（文本、图片、视频）、文物推荐（同作者、相似主题、图像识别）
   - 数据查询：简单查询（关键字、名称、年代）、高级查询（限定查询）
   - 数据可视化：知识图谱可视化（力导向图）、时间轴展示
   - 用户个人信息：登录、注册、修改信息、浏览记录、收藏、评论
   - 知识问答：知识图谱高级检索、人机交互

2. **项目框架确定**：
   - VUE.js + d3.js + SSM（Spring Boot + MyBatis + SpringMVC）+ MySQL + neo4j

3. **分工安排**：
   - 万玉贤：初期框架搭建、用户个人信息管理、版本管理
   - 欧阳雨青：前端页面美化、文物数据浏览功能
   - 姜轶文：数据查询功能实现（不包括知识图谱查询）
   - 陈璐：知识图谱可视化及查询、时间轴、统计面板可视化
   - 倪亚伦：地理分布图、统计面板可视化
   - 詹伟豪：分支合并、测试、调试

4. **第一周任务**：学习各自负责的框架技术

## 第二次会议纪要 — 进度汇报与UI设计统一

**会议性质**：进度跟踪与方案讨论会议

### 本周个人汇报：
- 万玉贤：编写用户登录、注册、修改信息、注销后端代码，进行版本管理
- 欧阳雨青：学习前端框架、AJAX，编写简单的前端数据浏览页面，提供接口
- 姜轶文：学习后端Spring Boot + MyBatis框架，代码可运行，开始数据查询功能开发
- 陈璐：学习neo4j数据提取后端代码，帮助第一小组做知识图谱、IDEA环境搭建
- 倪亚伦：学习时间轴制作工具，学习VUE，编写简单的前端代码
- 詹伟豪：学习数学建模、实体识别、需求文字信息提取，准备测试用例

### 遇到的问题与解决：
- **UI界面设计存疑，前端页面设计不清晰** → 经讨论统一意见，确定五个基础页面：
  1. 首页：包含用户登录、时间轴以及知识图谱
  2. 登录后首页：包含用户信息、知识图谱、时间轴、搜索框
  3. 搜索页面：搜索框、搜索导航栏（按作者、年份、材质等分类搜索）
  4. 文物单独展示页面：图片、文物详细信息、简介等
  5. 用户后台界面：修改个人信息、查看评论、查看收藏文物

### 下周任务：
- 着手写代码
- 前端：五个基础界面实现、时间轴展示
- 后端：编写文物数据获取接口、按作者/材质/年份等查找文物
- 向团内提交相关表的字段需求
