## 二、各成员详细分工

### 1. 张芷淇（组长）— 核心层

#### 负责模块

| 模块 | 负责内容 | 主要文件 |
|------|----------|----------|
| 答案溯源 | 工具输出溯源提取、Neo4j↔MySQL 桥接补全、聚合查询样本链接 | `app/core/source_extractor.py` |
| 图谱事实格式化 | 区分图谱事实与 LLM 润色内容 | `app/core/kg_facts_formatter.py` |
| 答案构建 | Agent 结果 + LLM 润色 → 标准 `AskResponse`；空结果处理与溯源标注 | `app/core/answer_builder.py` |
| 用户反馈 | 管理端会话鉴权；`done` 消息携带 `message_id` 与溯源信息 | `app/core/admin_session.py`、`app/api/admin_router.py` |
| 实时通信 | 统一 WebSocket 协议（chunk / done / agent_step 等）；断线重连与游标续写 | `app/core/ws_manager.py` |
| 架构优化 | 溯源 / 答案 / 反馈模块解耦；对话逻辑优化；代码调试与整体联调 | 跨模块协调 |

### 4. 熊佳惠 — 检索层

#### 负责模块

| 模块 | 负责内容 | 主要文件 |
|------|----------|----------|
| MySQL 检索 | artifact 表只读查询（6997 条记录，35 字段） | `app/agents/tools/mysql_tool.py` |
| Neo4j 检索 | 知识图谱只读 Cypher 查询（6875 节点，11 类节点，8 条关系） | `app/agents/tools/neo4j_tool.py` |
| 安全校验 | SQL/Cypher 只读强制、LIMIT 强制、黑名单过滤 | 各 `validate_*` 函数 |
| 工具注册 | 按配置动态装配 MySQL / Neo4j / summarize 工具 | `graph_agent.py` 内 `get_available_tools()` |

#### 负责文档

| 文档 | 内容 |
|------|------|
| `qa_system/docs/05_Agent与Tool设计.md` | MySQL 9 个 Tool、Neo4j 3 个 Tool、安全校验机制（与王海光协作） |

#### 负责测试

| 测试类别 | 测试用例范围 |
|----------|--------------|
| 简单问答 | TC-1.x：10 类问题（收藏地、年代、材质、类型、介绍、作者等） |
| 复杂问答 | TC-4.x：多步推理、关系查询、统计聚合 |
| 安全校验 | 拒绝 DELETE/UPDATE/MERGE 等写操作；强制 LIMIT |
| 自动路由 | Graph Agent 自动选择 MySQL 或 Neo4j |
| 答案溯源字段 | 返回 `sources` 标明数据来源 |

#### 协作事项

- 接受 **王海光** Graph Agent 的查询意图，返回结构化检索结果
- 依赖 **张士杰** 提供的数据库连接与 Mock 环境
- 与 **张芷淇** 对接检索结果格式，支撑溯源与 `kg_facts` 生成
- 与 **马明晓** 对接 `summarize_result` 工具，将原始数据转为自然语言

### 5. 马明晓 — 大模型接入层

#### 负责模块

| 模块 | 负责内容 | 主要文件 |
|------|----------|----------|
| LLM 接入 | HTTP 直调通义千问等 OpenAI 兼容 API | `app/retrieval/llm_generator.py` |

| 幻觉防控 | System Prompt 约束 + 代码层空结果拦截 | 贯穿 Agent 调用链 |
| 成分标注 | 区分「图谱事实」与「LLM 润色」 | 与 `kg_facts_formatter` 协作 |

#### 负责文档

| 文档 | 内容 |
|------|------|
| `qa_system/docs/01_系统架构.md` | LLM 接入架构流程（与其他成员协作） |
| `qa_system/docs/05_Agent与Tool设计.md` | System Prompt 设计、幻觉防控策略 |

#### 负责测试

| 测试类别 | 测试用例范围 |
|----------|--------------|
| LLM 润色 | 回答语言流畅，不脱离数据库事实 |
| 幻觉防控 | 无图谱事实时阻断 LLM 调用，返回「暂无相关数据」 |
| 意图识别 | 11 类意图正确路由到对应检索策略 |
| Mock 切换 | `MOCK_MODE=False` 后无缝接入真实数据库 |
| 成分标注 | 前端正确展示合规声明（图谱事实 vs LLM 生成） |

#### 协作事项

- 与 **张芷淇** 对接答案构建，确保润色不编造、空结果走 `not_found`
- 与 **熊佳惠** 对接 `summarize_result`，将 Tool 原始输出转为 RAG Context
- 与 **张士杰** 使用 Mock 模块并行开发，数据库就绪后一键切换
- 与 **王海光** 对接 Main Agent 流式 token 生成

## 三、跨成员协作矩阵

| 协作接口 | 涉及成员 | 协作内容 |
|----------|----------|----------|
| WebSocket 协议 | 张芷淇 ↔ 王海光 | 统一 chunk / done / agent_step 消息格式，前端渲染对齐 |
| 双 Agent 流水线 | 王海光 ↔ 熊佳惠 ↔ 马明晓 | Graph Agent 检索 → summarize → Main Agent 润色 → 流式输出 |
| 答案溯源链路 | 熊佳惠 → 张芷淇 | 检索结果 → SourceExtractor 桥接 → sources 链接生成 |
| 数据库基础设施 | 张士杰 → 全员 | 统一连接池、Mock 环境、ai_history 表 |
| 幻觉防控体系 | 马明晓 ↔ 张芷淇 ↔ 熊佳惠 | Prompt 约束 + 空结果拦截 + 只读校验三层防护 |
| 前后端联调 | 张芷淇 ↔ 王海光 | 反馈提交、断线续传、RAG 可视化、管理端 |
| 独立开发保障 | 张士杰 ↔ 马明晓 | MockRetriever 解耦，各模块可并行开发测试 |
