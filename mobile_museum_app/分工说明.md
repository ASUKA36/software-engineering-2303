# 掌上博物馆 — 组员分工说明

## 巫昊洋

- 负责文物详情页开发，含多图轮播、全屏缩放与属性信息展示

## 侯程耀

- 负责搜索页整体开发与交互逻辑
- 负责关键字、朝代、博物馆多条件组合检索
- 负责搜索元数据加载（朝代列表、博物馆列表）
- 负责语音搜索功能，对接 HarmonyOS ASR 语音识别

**重点模块**：搜索与分类发现（`SearchPage`、`SpeechSearchService`、`/api/artifacts/search`）

## 王希童

- 负责用户登录页、注册页 UI 与表单校验
- 负责登录注册接口对接（`MuseumService.login`、`register`）
- 负责会话状态管理（`UserSession` 内存保存 token 与用户信息）
- 负责各页面登录引导与未登录拦截逻辑（`requireLogin`）

**重点模块**：用户注册登录与会话（`LoginPage`、`RegisterPage`、`UserSession`、`/api/auth/*`）

## 甘博宁

- 负责详情页点赞、收藏、评论交互区开发
- 负责收藏夹分组创建与文物移动收藏功能
- 负责评论发表、回复他人评论及删除自己的评论
- 负责个人中心点赞、收藏、评论列表展示与审核状态呈现

**重点模块**：用户点赞、收藏与评论互动（`user_like`、`user_favorite`、`comment` 相关接口）

## 陆俊龙

- 负责文物详情页用户图片上传功能（选图、说明、地点填写）

- 负责待审核内容提醒（评论/图片待审计数与黄色提醒条）
- 负责本机浏览历史记录（`BrowseHistoryStore`）的存储与展示

**重点模块**：用户上传与个人内容管理（`ProfilePage`、`ProfileAccountPanel`、`/api/user/photos`）

## 薛度扬

- 负责多子系统地址配置（`Constants.ets` 中业务 API、图片 API、问答 API）
- 负责组内/组间联调协调、健康检查与测试脚本维护
- 参与文物浏览、搜索、登录、互动、上传等模块的开发与集成工作

**重点模块**：以图搜图功能与组内/组间联调（`image_search.py`、`SearchPage` 以图搜图、`run_project_tests.py`）
