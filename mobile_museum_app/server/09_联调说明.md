# 文物问答后端 API 联调说明

> 给掌上博物馆等子系统同学使用。如有问题联系后端负责人。

---

## 一、服务地址（直接用这个）

| 用途 | 地址 |
|------|------|
| 服务根地址 | `http://10.4.161.20:8000` |
| API 前缀 | `http://10.4.161.20:8000/api/qa` |
| 在线接口文档（Swagger） | http://10.4.161.20:8000/docs |
| 健康检查 | http://10.4.161.20:8000/health |
| WebSocket | `ws://10.4.161.20:8000/api/qa/ws?session_id={session_id}` |

**联调前提：**

1. 知识问答子系统在本机已启动服务（端口 8000）
2. 在**同一校园网 / 同一 WiFi**
3. 浏览器或 Postman 先访问 http://10.4.161.20:8000/health ，应返回 `{"status":"ok",...}`

> IP 可能会变（重连 WiFi 后）。若连不上，让负责人重新 `ipconfig` 确认 WLAN 的 IPv4。

---

## 二、接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/qa/session` | 创建会话，获取 `session_id` |
| `WS` | `/api/qa/ws?session_id=...` | **推荐** 流式问答 |
| `POST` | `/api/qa/ask` | 非流式问答（简单场景可选） |
| `GET` | `/api/qa/history/{session_id}` | 查询会话历史 |
| `DELETE` | `/api/qa/session/{session_id}` | 删除会话 |
| `POST` | `/api/qa/feedback` | 提交「有帮助 / 不准确」反馈 |
